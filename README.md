# AI Workbench

A personal dumping ground for small AI-generated utilities, prompts, instruction sets, experiments, and other reusable artifacts that do not warrant their own repository.

## Projects

- [`network-automation-agent-instructions/`](network-automation-agent-instructions/) — Personal engineering instructions for VS Code/Copilot and compatible tools, including Python and Ansible-specific rules plus manual `/network-change` and `/ai-status-check` skills.

## Intent

Content in this repository is personal tooling. It is not intended to impose standards on unrelated shared repositories or other contributors.

Each subdirectory should be self-contained and include its own README when setup or usage is not obvious.
